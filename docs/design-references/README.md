# Design references

Brand `DESIGN.md` files from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)
(MIT), kept for reference — **not** Bento's design. Bento's own system is
[`../../bento/DESIGN.md`](../../bento/DESIGN.md); when they disagree, Bento wins.

| File | Why it's here |
|---|---|
| `airbnb.DESIGN.md` | Consumer travel: trip and booking flows, date pickers, warm single-accent palette |
| `linear.DESIGN.md` | Dense app layout, keyboard-first, quiet chrome around content |
| `notion.DESIGN.md` | Calm document-style surfaces, side panels, readable long text |

Borrow specific ideas (spacing, a component pattern); don't import a brand's
colours, fonts or logo treatment.
