# D5: User zero: the owner is the first traveller

## Context
Designing onboarding against an invented persona produces questions nobody asks.

## Decision
The owner is the first real traveller. Onboarding, curation priority and the first evaluation scenario are designed against the owner's real preferences.

## Consequences
Design choices have a real person to be checked against. The profile itself is personal, so it's kept in the private vault, not in this repo.

## Today
In effect. The profile is in the private vault (`bento-private`).
