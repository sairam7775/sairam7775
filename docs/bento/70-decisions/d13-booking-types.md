# D13: Booking types: five core types and "other"

## Context
The gap detector needs to know what kind of booking covers what.

## Decision
Flights, accommodation, intercity transport, tickets and restaurants, plus "other" for anything else.

## Consequences
The five core types drive gap detection (see [booking vault](../10-product/booking-vault.md)).

## Today
In effect.
