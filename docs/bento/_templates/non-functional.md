# Requirement area

## Target
What must be true, stated so it can be checked. If no target is set yet, say so under Known gaps; don't invent one.

## How it's checked
The test, constraint, log query or review that proves it.

## Evidence
Links to tests, migrations, PRs or recorded checks. Never "should".

## Known gaps
What isn't covered yet, and the risk.
