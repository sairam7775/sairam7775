# Bento — screen designs

Six traveller-facing mock-ups from the second design direction: **the app is a bento box**. Lacquer-dark frames hold compartment tiles in food colours (salmon, tamago yellow, edamame green, umeboshi red) on warm rice white.

**These are mock-ups, not the source of truth.** What's built is described in the docs vault, [design](../docs/bento/20-design/README.md), and defined by `bento/DESIGN.md` and `bento/src/app/globals.css`, which win if they disagree with these files.
- The fonts in these artboards (Bricolage Grotesque headlines, DM Sans body) were an earlier exploration. The app uses Zen Maru Gothic headlines, Zen Kaku Gothic New body and DM Mono data, and keeps Bricolage Grotesque only for the logo's wordmark.
- The status of each artboard (current, exploratory or inspiration) is listed on the design page in the vault.

`_shared_head.txt` is the shared font link and style block every artboard starts with: edit it once, re-seed, and all six pick it up.
